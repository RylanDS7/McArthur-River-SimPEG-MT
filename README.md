# McArthur-River-SimPEG-MT

SimPEG MT inversion for line 304 of the [McArthur River MT Dataset](https://open.canada.ca/data/en/dataset/6c6baf28-f8d4-5c8b-9463-73f6bf6dea2a).

Inversions were run using different frequency data cutoffs determined by how many recievers were required to have data on a frequency for it to be valid. Inversion results and related graphics are given in the figures folder.
